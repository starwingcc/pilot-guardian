实现含义（评审通过后落地）

  1. 保存模型：sticky 操作条跟随编辑器，「保存更改」沿用 config:save-rule 保存当前规则，「放弃更改」恢复到最近一次已保存版本；头部只保留导入 / 导出与同步徽章。
  2. 策略模式：两个开关映射现有 RuleMode——仅挑战 = password、仅时间 = schedule、双开 = combined，领域类型无需变更。
  3. 受控目标改为 chips 输入；校验复用 parseUrlPattern，重复与范围重叠提示内联到对应 chip 与卡片底部。
  4. 挑战序列、周期安排作为策略开关的子面板联动展开 / 收起（本页开关可实际点按体验）。
  5. 深链：弹窗「编辑这条规则」跳转 options.html?rule=<id> 预选并滚动定位到该规则。
  6. 排序沿用 config:reorder-rules；rail 箭头保证键盘可达性，拖拽排序列为后续增强。
